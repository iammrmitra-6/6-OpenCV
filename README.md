# OpenCV Practice Project

This folder contains basic OpenCV exercises and image-processing examples.

## Contents
- `main.ipynb` — main notebook with OpenCV learning examples
- `createcircle.py` — mouse-click drawing example
- `createrectangle.py` — drag-to-draw rectangle example
- `croppingtool.py` — crop-by-drag tool using the airplane sample image
- `aeroplane.png` — sample image used in experiments
- `Mango.png` — sample image used for image-processing tasks

## Typical workflow
1. Open the notebook and run the cells in order.
2. Use the Python scripts for interactive drawing and cropping demos.
3. Keep generated output images in the same project folder while working locally.

## Setup
```bash
python -m venv .venv
. .venv/bin/activate   # Linux/macOS
.venv\Scripts\activate # Windows
pip install opencv-python
```
